# Light and Dark Mode Images

Give the featured image and Image blocks a second version for the other color scheme. Visitors in dark or light mode see the matching image.

- Second featured image in the post sidebar (meta box in the classic editor)
- Second image for the Image block in its block settings
- Standard `<picture>` output with `prefers-color-scheme`, no JavaScript needed
- Light or dark as the base scheme
- Optional selectors for a theme's own light/dark switch

Settings > Media. Requires WordPress 6.5 and PHP 7.4. Details in [readme.txt](readme.txt).
